# Blog Application

## Overview

The Blog Application allows users to view, create, edit, and delete blog posts. It demonstrates CRUD operations in a modern web application.

## Features

- Create Blog
- View Blogs
- Edit Blog
- Delete Blog
- Responsive User Interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Project Structure

```
src/
components/
App.jsx
package.json
README.md
```

## Expected Output

Users can manage blog posts through an interactive interface.
