# Contact Book Application

## Overview

The Contact Book is a web application that allows users to manage personal contacts. Users can add, edit, delete, and search contacts efficiently.

## Features

- Add Contact
- Edit Contact
- Delete Contact
- Search Contact
- Responsive Interface

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Expected Output

Users can manage contact information through an intuitive interface.
