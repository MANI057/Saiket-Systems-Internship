# Number Guessing Game

## Overview

This project is a Number Guessing Game where users attempt to guess a randomly generated number. The application provides hints until the correct number is guessed.

## Features

- Random Number Generation
- User Input
- Higher/Lower Hint
- Winning Message
- Restart Game

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Expected Output

The application guides the user to guess the correct number with appropriate hints.
