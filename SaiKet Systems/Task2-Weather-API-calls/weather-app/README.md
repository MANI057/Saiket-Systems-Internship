# Weather API Application

## Overview

This project fetches real-time weather information using a Weather API. Users can search for any city and view the current weather conditions.

## Features

- Search weather by city
- Temperature
- Humidity
- Wind Speed
- Weather Description
- Error handling for invalid city names

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Weather API
- Vite

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## API Used

Weather API for fetching real-time weather data.

## Expected Output

Displays:

- City Name
- Temperature
- Weather Condition
- Humidity
- Wind Speed
